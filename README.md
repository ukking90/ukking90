## 👨‍💻 About Me

2014년부터 다양한 제품을 직접 만들어온 **풀스택 개발자**입니다.
멋진 기술 용어보다 **"맡은 걸 끝내 동작하게 만드는 것"**을 가장 중요하게 생각합니다.

- 🚀 **완수력** — 요구사항을 받으면, 어떤 방식으로든 **동작하는 결과물**로 끝냅니다. 15년간 수많은 웹 프로젝트를 완주했습니다.
- 🖥️ **프론트엔드** — Vue 기반으로 데이터 그리드·차트·복잡한 화면을 구현합니다.
- ⚙️ **백엔드** — Kotlin / Java + Spring으로 REST API와 비즈니스 로직을 만듭니다.
- 🧩 **혼자서 끝까지** — 기획·프론트·백엔드·배포까지 한 사람이 책임지는 1인/소규모 개발에 익숙합니다.
- 🌱 **요즘 공부 중** — 리액티브 백엔드(Spring WebFlux / R2DBC)와 시계열 데이터(TimescaleDB)로 영역을 넓혀가고 있습니다.
